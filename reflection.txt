At the beginning of this assignment, I did not clearly understand what a Git repository was. Because of this, I initially created my assignment HTML file inside my practice folder, which already contained multiple HTML files from lecture code examples. Later, I realized this was not the correct approach and created a separate folder specifically for the assignment. I also encountered challenges with the layout, especially when using flexbox to stack the map and content elements properly. It took time to understand how flexbox works and how small changes in CSS can affect the overall layout. Additionally, I noticed several grammar and syntax errors in my code, such as misspelling label as lable. I also struggled with correctly adding class names, particularly understanding how to use quotation marks('"), the differences between hyphens (-) and underscores (_), and how to select elements using CSS class selectors. I attempted to create a hide-and-show functionality but was unable to successfully toggle the visibility of elements. As an alternative solution, I implemented a function that centers the map and shows the content instead. Through this process, I learned the importance of proper file organization, attention to syntax details, and planning functionality before implementing it in code.
